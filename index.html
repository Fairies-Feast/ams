Amsilla AMS

Install .ams apps on all systems!

How to Install

Most Linux Distros

1. Download ams-install.sh
2. Run "sudo bash ams-install.sh" in the terminal. 3. If the installation fails, see the "Other OS" category.

Windows & MacOS

Windows & MacOS guided installers are not ready yet. See the "Other OS" category to install.

Other OS

1. Install/download Python. 2. Download ams-app.py 3. Run ams-app.py every time you want to open AMS.
